1. As an administrator, open **Contacts → Configuration → Localization → Cities** and search
   for a postal code: the Slovak localities of that postal code are listed with their region.

   ![Cities list filtered on the postal code 949 01: three localities (Lužianky, Nitra, Nitrianske Hrnčiarovce) of the region Nitriansky kraj (SK)](static/description/en/01_lista_localitati_cap.png)

2. Open a Slovak contact and type the postal code in the address: the city and the region are
   filled in.

   ![Contact in Slovakia: the postal code 811 01 fills in the city Bratislava-Staré Mesto and the state Bratislavský kraj (SK)](static/description/en/02_partener_cap_unic.png)

3. When the postal code is shared by several localities, only the region is filled in; choose the
   city from the list (type the postal code or the name in the city field).

   ![Contact in Slovakia: the postal code 949 01 fills in the state Nitriansky kraj (SK); the city field lists the localities of 949 01](static/description/en/03_partener_cap_comun.png)

4. To complete existing or imported contacts, select them in the list and run
   *Actions → Slovakia: set city from ZIP*.

   ![Contacts list with Slovak contacts selected and the Actions menu open on Slovakia: set city from ZIP](static/description/en/04_actiune_contacte_existente.png)

   ![Contact Zákazník Žilina after the action: ZIP 010 01, city Žilina (010 01) and state Žilinský kraj (SK)](static/description/en/05_contact_dupa_actiune.png)
