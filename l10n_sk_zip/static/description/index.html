Slovakia - City from ZIP

Loads the Slovak localities (obce) with their postal code and region, and fills in the city and the region of Slovak addresses from the postal code.

  • Ships the list of Slovak localities with their postal code, linked to the regions of Slovakia. The data comes from GeoNames (Creative Commons Attribution 4.0).
  • Slovakia is set to enforce cities: the city of a Slovak address is chosen from the list.
  • On the contact form, typing the postal code (PSČ) of a Slovak address sets the city and the region. A postal code shared by several localities sets only the region; the city name, when it matches one of them (without accents and case), picks the locality.
  • The action Slovakia: set city from ZIP on contacts links the Slovak contacts to the city of their postal code and fills in the region.
  • At install, the Slovak contacts are linked: directly on a small database, by the scheduled action Slovakia: link contacts to the city of their ZIP in batches on a large one (it deactivates itself when done).
  • Every form that runs the postal code rules of the contact (for example the delivery details of an AWB) gets the region filled in, so the shipment can be sent to Slovakia without looking it up by hand.

Usage

  1. As an administrator, open Contacts → Configuration → Localization → Cities and search for a postal code: the Slovak localities of that postal code are listed with their region.

  2. Open a Slovak contact and type the postal code in the address: the city and the region are filled in.

  3. When the postal code is shared by several localities, only the region is filled in; choose the city from the list (type the postal code or the name in the city field).

  4. To complete existing or imported contacts, select them in the list and run Actions → Slovakia: set city from ZIP.
